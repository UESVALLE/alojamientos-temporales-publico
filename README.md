# UESVALLE · Alojamientos Temporales (edición pública)

Tablero de vigilancia sanitaria y seguimiento poblacional de alojamientos temporales en el Valle del Cauca.

- **Versión:** V6.4
- **Corte:** 9 de noviembre de 2026
- **Fuente del conteo poblacional:** hoja «Censo total Valle» del consolidado institucional del 9 de noviembre de 2026
- **Total censado:** 124 personas, 10 alojamientos reportados, 7 municipios
- **Cobertura incompleta:** 7 alojamientos de Yotoco y Restrepo sin reporte en noviembre (no se interpretan como cerrados)
- **Históricos:** 3 cierres previamente reportados

## Publicación

El sitio web se sirve desde `/dashboards/alojamientos_temporales/alojamientos_temporales.html`. `index.html` redirige a esta ruta. Para activarlo en GitHub Pages, vaya a **Settings → Pages → Deploy from a branch → main → /(root)**.

## Datos y privacidad

Solo se incorporan datos estadísticos agregados, identificadores y descripciones operacionales de los sitios. **No se publica el censo individual, nombres de las personas alojadas, documentos, teléfonos, EPS individuales, historia clínica, archivos originales ni fotografías**. El módulo de seguimiento interno se omite de la edición pública. Toda observación sanitaria es histórica o declarativa según se indica en su ficha y no constituye una visita nueva.

El repositorio privado institucional de UESVALLE permanece separado. La copia pública debe revisarse antes de divulgar nuevas versiones o datos.
